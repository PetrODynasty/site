# Sealforge Arena: 2D Edition

2D roguelike action-RPG, созданный в Godot 4.

## Цель
Динамичный рогалик с элементами экшен-RPG: исследование процедурно сгенерированных уровней, бои в реальном времени, прокачка, лут.

## Структура
- `scenes/` — игровые сцены (.tscn)
- `scripts/` — скрипты на GDScript/C#
- `ui/` — интерфейс
- `art/` — спрайты, тайлсеты, анимации
- `data/` — данные (ресурсы Godot, JSON)
- `addons/` — аддоны

## Запуск
1. Открыть проект в Godot 4.x
2. Запустить главную сцену `scenes/main/Main.tscn`
